# Changelog

## 1.0.0-preview.1 — 2026-10-20

First public source preview: native iPhone/iPad/Mac apps, local records and goals, rule-based assistant, CSV/PDF intake and JSON export. Includes a dependency-free static website, bilingual README, representative screenshots, reproducible build/test scripts and GitHub Actions checks.

Installers, completed videos and PDF guides are distributed as Release assets, not committed source. This is not an App Store release, medical device or production-validated clinical product.
