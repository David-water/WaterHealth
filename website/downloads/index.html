下载并打开

点击上方「下载 Mac 安装包」。下载完成后，在「下载」文件夹中双击 WaterHealth-macOS.dmg。

拖入应用程序

将磁盘映像内的 WaterHealth 拖入 Applications（应用程序）文件夹。安装后可推出磁盘映像。

启动与体验

从「应用程序」打开 WaterHealth。首次启动可创建个人档案，或选择「体验演示档案」探索功能。

首次打开：系统可能要求你确认。

当前 Mac 体验版采用本地 ad-hoc 签名，尚未取得 Apple Developer ID 签名与公证。系统可能提示无法验证开发者或无法确认是否包含恶意软件。确认文件来自本官网、核对下方 SHA-256 后，请按 Apple 提供的流程操作：

  1. 先从「应用程序」尝试打开 WaterHealth 一次。
  2. 打开「系统设置 → 隐私与安全性」，在 WaterHealth 的安全提示旁选择「仍要打开」。
  3. 根据系统提示再次选择「打开」，必要时输入你自己的 Mac 登录密码。

无需关闭 Gatekeeper，也无需安装 Xcode。Apple 官方首次打开说明

如果提示「这台 Mac 不支持此应用程序」，请确认你使用的是本页的 macOS 安装包，且系统版本为 macOS 14 或更新版本。旧的 iOS 模拟器包无法在 Mac 上双击运行。
