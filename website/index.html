你可能还想了解。

为什么旧的 WaterHealth.app 在 Mac 上无法打开？

旧包面向 iOS 模拟器，不能当作 macOS 应用启动。这里提供的是重新构建的 macOS 原生通用应用，包含 Apple 芯片与 Intel 架构，最低支持 macOS 14。安装此版本无需 Xcode。

iPhone 和 iPad 现在可以直接下载安装吗？

当前尚未开通 Apple Developer / TestFlight 分发。官网先提供 Mac 安装包，iPhone、iPad 的界面和功能已经在原生模拟器中验证；手机和平板的免编译安装入口将在合法签名与分发配置完成后提供。

首次打开 Mac 体验版，需要做什么？

下载 DMG，打开后将 WaterHealth 拖入「应用程序」。此体验版尚未经过 Apple Developer ID 签名与公证，系统可能阻止首次启动。请先核对官网下载来源，然后根据下载页的说明，在「系统设置 → 隐私与安全性」中选择「仍要打开」。无需关闭系统安全保护。

健康助手、年龄报告和营养药房如何工作？

助手使用本地规则整理记录、提供应用导航，没有接入云端大模型。生物年龄、风险百分比与年龄相关读数是标注清楚的演示示意。营养药房是本地模拟体验；不提供医疗诊断、处方、支付或发货。
