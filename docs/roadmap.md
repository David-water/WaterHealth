# Proposed roadmap

These are contribution ideas, not committed delivery dates or current capabilities.

- [ ] Add an English app localization while preserving Simplified Chinese.
- [ ] Validate HealthKit permission denial, no-data, locked-device and real-record flows on actual devices.
- [ ] Audit Dynamic Type, VoiceOver and keyboard/focus behavior.
- [ ] Design a versioned JSON restore/migration flow with recovery tests.
- [ ] Expand import/error-path tests around documented CSV/PDF contracts.
- [ ] Prepare owner-managed signing/notarization and TestFlight distribution.

Use an issue to discuss behavior, privacy implications and validation before adding integrations. Core flows should remain useful offline; new cloud services or SDKs need an explicit decision.
