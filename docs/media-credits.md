# Release media and credits

Release videos are produced from real native app/simulator recordings and screenshots containing fictional demo data. Mac screenshots are from the native macOS target. No patient records or real orders are shown.

- Brand mark: original WaterHealth W / water-drop artwork.
- Anatomical illustrations: AI-assisted reconstruction, illustrative rather than clinical imagery.
- Design reference: [George Railean's ClyHealth case study](https://www.georgerailean.com/work/clyhealth); no affiliation or endorsement.
- Music and riser: original deterministic program-generated audio for the project.
- Narration: macOS Tingting system Chinese voice. System voice/font software is not bundled.
- Shot references/implementations used by the video production project: video-shotcraft, Apache-2.0. License copy: [shotcraft-APACHE-2.0.txt](licenses/shotcraft-APACHE-2.0.txt).
- Transition/impact/sparkle sounds: Mixkit, under its applicable [Sound Effects License](https://mixkit.co/license/#sfxFree). Source details are listed below.

This minimal repository contains the app/site source and small documentation images, not the renderer, original sound library, raw recordings, QA captures or media caches. Finished videos are Release artifacts. Do not treat separately licensed sounds as a freely redistributable standalone sound pack.
