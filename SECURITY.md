# Security and sensitive data

Do not publish real health data, keys or exploit details in public issues.

Use [GitHub private vulnerability reporting](https://github.com/David-water/WaterHealth/security/advisories/new) to report a sensitive issue. Include the affected commit/version, platform, fictional reproduction steps, expected behavior and impact. Please omit patient data and unrelated personal information.

This is a preview project; there is no promised response-time SLA or clinical/security certification. The default branch is the currently maintained code line. Older preview binaries should not be assumed to receive automatic updates.

Core records are local. File protection and sandboxing do not replace backups or device security. JSON exports can contain sensitive records; attachments are stored separately. There is no cloud backup or JSON restore yet.
